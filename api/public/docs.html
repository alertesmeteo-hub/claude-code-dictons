API Alertes-Meteo

Une API meteo francaise simple a integrer. Format JSON, cle gratuite. Fichier OpenAPI (compatible Swagger UI).

1. Demander une cle gratuite

curl -X POST https://api.alertes-meteo.com/v1/keys/requests \
  -H "Content-Type: application/json" \
  -d '{"name":"Votre nom","email":"vous@exemple.fr","usage":"Affichage du lever du soleil sur mon site meteo local, environ 100 appels par jour.","consent":true}'

Chaque demande est examinee manuellement, puis la cle est envoyee par email. Elle est valable 2 ans. Envoyez-la dans l'en-tete X-API-Key. Ne la mettez jamais dans du code public cote navigateur. Nous ne conservons que son empreinte. Les informations de la demande servent uniquement a la traiter.

2. GET /v1/sun

Lever, coucher, midi solaire, aube et crepuscule, calcules localement.

ParametreRequisDescription
latouiLatitude, -90 a 90
lonouiLongitude, -180 a 180
datenonYYYY-MM-DD, defaut aujourd'hui
tznonFuseau IANA, defaut Europe/Paris

cURL

curl "https://api.alertes-meteo.com/v1/sun?lat=48.8566&lon=2.3522&date=2026-06-21" -H "X-API-Key: VOTRE_CLE"

JavaScript

const r = await fetch("https://api.alertes-meteo.com/v1/sun?lat=48.8566&lon=2.3522", {
  headers: { "X-API-Key": "VOTRE_CLE" }
});
console.log(await r.json());

PHP

$ctx = stream_context_create(['http' => ['header' => "X-API-Key: VOTRE_CLE\r\n"]]);
echo file_get_contents('https://api.alertes-meteo.com/v1/sun?lat=48.8566&lon=2.3522', false, $ctx);

Python

import requests
r = requests.get("https://api.alertes-meteo.com/v1/sun",
                 params={"lat": 48.8566, "lon": 2.3522}, headers={"X-API-Key": "VOTRE_CLE"})
print(r.json())

Reponse

{
  "data": { "date": "2026-06-21", "timezone": "Europe/Paris",
    "sunrise": "2026-06-21T05:47:00+02:00", "solar_noon": "...", "sunset": "...",
    "dawn": "...", "dusk": "...", "day_length_seconds": 58000, "polar": null },
  "meta": { "source": "Calcul local (algorithme NOAA)", "stale": false,
    "version": "v1", "units": "metric", "generated_at": "..." }
}

Actualisation : calcul a chaque requete, aucune donnee externe. En zone polaire, les heures sont null et polar vaut day ou night.

3. GET /v1/extremes/france

Temperatures maximale et minimale du jour parmi les stations Meteo-France collectees. Ce ne sont pas des records officiels.

ParametreRequisDescription
altitude_maxnonAltitude maximale des stations, en metres (ex. 500)
stationsnontoutes (defaut) ou principales (reseau RADOME)
curl "https://api.alertes-meteo.com/v1/extremes/france?altitude_max=500" -H "X-API-Key: VOTRE_CLE"

Reponse : data.max et data.min (temperature, station, departement, altitude, heure d'observation UTC). meta.updated_at, meta.stale et meta.coverage (departements collectes) indiquent la fraicheur et la completude ; si coverage.complete vaut false, l'echantillon est partiel.

Source : Meteo-France (observations horaires), retraitees par Alertes-Meteo. Actualisation : toutes les heures.

4. GET /v1/vigilance

Niveaux de vigilance par departement et par phenomene, pour aujourd'hui (J) et demain (J1). Service non officiel, a titre informatif : la reference reste vigilance.meteofrance.fr.

ParametreRequisDescription
domainnonDepartement (30, 2A) : renvoie aussi sa zone cotiere (3010). Un code a 4 caracteres cible uniquement la zone cotiere.
echeancenonJ ou J1
min_levelnon1 (vert) a 4 (rouge). Defaut 2 : seules les vigilances jaune et plus sont listees.
curl "https://api.alertes-meteo.com/v1/vigilance?domain=30" -H "X-API-Key: VOTRE_CLE"
{ "data": { "periods": [ { "echeance": "J", "domains": [ { "domain_id": "30", "max_level": 3,
    "phenomena": [ { "phenomenon_id": 3, "phenomenon": "orages", "level": 3, "color": "orange",
      "begin": "2026-09-20T04:00:00+00:00", "end": "2026-09-20T22:00:00+00:00" } ] } ] } ] },
  "meta": { "source": "...", "product_at": "...", "updated_at": "...", "stale": false } }

Une liste periods vide signifie qu'aucune vigilance ne depasse min_level. meta.product_at est la date du produit source, meta.updated_at la derniere verification, et meta.stale passe a true si elle date de plus de 45 minutes. Actualisation : verification toutes les 15 minutes.

5. GET /v1/records

Records de temperature du jour, calcules par comparaison a l'historique de chaque station. Ils sont provisoires et non officiels : ne les presentez pas comme des records de France.

ParametreRequisDescription
kindnonheat (chaleur), cold (froid), tropical (nuit tropicale)
scopenonPortee du record battu : absolute, monthly, fortnight, daily
departmentnonDepartement (30, 2A)
limit / offsetnonPagination, 50 par defaut, 200 maximum
curl "https://api.alertes-meteo.com/v1/records?kind=heat&scope=absolute&limit=10" -H "X-API-Key: VOTRE_CLE"

Chaque element donne la station, la temperature en °C, les portees battues (scopes_beaten) et le record precedent avec sa date (previous_records). meta.coverage indique combien de departements ont un historique ; s'il est incomplet, des records peuvent manquer. Actualisation : toutes les 30 minutes environ.

6. GET /v1/rain

Pluie observee par station en metropole : derniere heure, 24 h, 48 h, 72 h glissantes, mois, saison et annee en cours, avec les normales 1991-2020 quand elles existent. Cumuls provisoires.

ParametreRequisDescription
sortnonTri decroissant : rr1, rr24 (defaut), rr48, rr72, month, season, year
departmentnonDepartement (30). La Corse est regroupee sous 20 pour ce jeu de donnees.
stationnonIdentifiant de station (8 caracteres)
complete_onlynon1 pour ne garder que les cumuls complets
limit / offsetnonPagination, 50 par defaut, 200 maximum
curl "https://api.alertes-meteo.com/v1/rain?sort=rr24&department=30&complete_only=1" -H "X-API-Key: VOTRE_CLE"

Chaque cumul indique complete et, pour 24/48/72 h, hours_covered : un cumul complete: false couvre moins d'heures que la periode annoncee, ne le presentez pas comme complet. Actualisation : toutes les 20 minutes environ.

Autres endpoints

  • GET /v1/usage : votre consommation.
  • DELETE /v1/keys : revoque la cle utilisee.
  • GET /v1/health : etat du service.

Sources et licences

Source : Meteo-France. Les endpoints extremes/france, vigilance, records et rain reposent sur des informations creees a partir de donnees de Meteo-France, reutilisees sous Licence Ouverte Etalab. Alertes-Meteo les retraite (agregation, calculs, mise en cache) : elles ne sont ni officielles ni validees par Meteo-France. Pour la vigilance officielle, consultez vigilance.meteofrance.fr. L'endpoint sun est calcule localement, sans donnee externe.

Erreurs

Format : {"error":{"code":"...","message":"..."}}. Codes : 401 cle invalide, 403 compte suspendu, 404 inconnu, 422 parametre invalide, 429 quota (voir Retry-After et X-RateLimit-*), 503 indisponible.

Offre gratuite : 30 requetes/minute, 10 000/mois.

Source : Meteo-France (donnees retraitees par Alertes-Meteo, service non officiel).
